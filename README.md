Портфолио аналитики данных в Excel
Обзор
Этот репозиторий содержит коллекцию аналитических проектов на базе Excel, ориентированных на бизнес-отчётность, разработку ключевых показателей эффективности, анализ продаж, создание панелей управления и трансформацию данных. Проекты демонстрируют практические навыки работы в Excel, часто используемые в ролях аналитика данных и бизнес-аналитика, включая продвинутые формулы, функции поиска, условные вычисления, анализ дат и визуализацию данных.
